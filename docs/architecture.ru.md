# Устройство

Пакет `dev.octrow.meetcaptions`, модуль `app/`. Тестовый двойник Meet — модуль `fakemeet/`.

```
событие доступности ──► CaptionService ──► BlockCollector ──► Block.parse ──► Transcript ──► файл
(Meet / Gmail)            окна Meet          обход дерева       «Имя: текст»     реплики       каждые 3 с
                              │                                                  │
                              └──► DebugRecorder (только в режиме отладки)        └── CaptionMerger на реплику
```

## Компоненты

| Файл | Что делает |
|---|---|
| `CaptionService.kt` | Служба. На каждое событие из Meet берёт все окна Meet, собирает снимок субтитров, передаёт в `Transcript`, планирует сохранение. Ведёт сессии (файлы). |
| `BlockCollector` (в `CaptionService.kt`) | Обходит дерево окна по порядку на экране. Узел, чей id подходит под regex имени, задаёт текущего говорящего; узел, подходящий под regex текста, даёт блок(и). |
| `Transcript.kt` → `Block.parse` | Разбирает текст субтитров построчно; префикс `Имя: ` перекрывает имя из отдельного узла. |
| `Transcript.kt` → `Transcript` | Список реплик (имя, время начала, склейщик). Решает, продолжается реплика или начинается новая. |
| `CaptionMerger.kt` | Склеивает последовательные снимки одной реплики без дублей. |
| `DebugRecorder.kt` | Режим отладки: `events_*.txt` и `dump_*.txt`. |
| `Prefs.kt` | Настройки: regex текста, regex имени, отладка. |
| `MainActivity.kt` | Экран настроек: кнопка в специальные возможности, два regex, переключатель отладки. |
| `res/xml/accessibility_service.xml` | Конфигурация службы: все типы событий, пакеты Meet и Gmail, `isAccessibilityTool`, `notificationTimeout=300`. |

## Как Meet показывает субтитры (S24, Android 16, Meet 379)

- Звонок из вкладки Meet в Gmail: пакет `com.google.android.gm`, активность
  `com.google.android.libraries.communications.conference.ui.callui.SingleCallActivity`.
  Из приложения Meet — `com.google.android.apps.tachyon`. Интерфейс звонка общий.
- Контейнер `…:id/captions_manager_placeholder` → `captions_manager_fragment_container` → `TextView` `…:id/captions_text`.
- В `captions_text` одна текущая реплика: `Dan P: так проверка с другого девайс 40 41`.
  При смене говорящего текст целиком заменяется на `Вы: …`.
- Обновления приходят как `TYPE_WINDOW_CONTENT_CHANGED` с источником `captions_text` примерно каждые 0,2–1 с.
- Последнее слово может показываться недописанным («провер» → «проверка»), ранние слова — менять регистр
  и пунктуацию («привет как» → «Привет, как»).

Настройки по умолчанию: regex текста `caption`, regex имени `speaker|participant_name`.

## Склейка субтитров

**`CaptionMerger`** хранит текущий блок слов. Для нового снимка берёт первые 3 слова (якорь) и ищет их в блоке:

1. Сравнение без учёта регистра и пунктуации.
2. Сначала ищется полное совпадение якоря (последнее в блоке). Всё до него уже уехало вверх и остаётся,
   остальное заменяется снимком: так учитываются и дописанные, и исправленные слова.
3. Если полного нет, якорь может выходить за конец блока (новые слова): нужно совпадение минимум
   2 слов (или всех, если блок короче), последнее слово блока может быть началом слова снимка.
4. Совпадения нет — блок закрывается строкой, снимок начинает новую.

**`Transcript`** работает с последним блоком снимка (живая реплика):

- то же имя → снимок уходит в склейщик текущей реплики;
- пустое имя → считается текущим говорящим (имя могло на миг пропасть);
- новое имя → новая реплика со временем; предпоследний блок снимка дописывается в старую;
- если текст под новым именем совпадает с последним текстом прошлой реплики (имя обновилось раньше текста),
  этот текст не копируется.

## Сохранение

- Файл сессии: `Documents/MeetCaptions/yyyy-MM-dd_HH-mm-ss.txt`, имя по времени первой реплики.
- Сохранение не чаще раза в 3 секунды, даже при непрерывной речи (таймер не сбрасывается новыми событиями).
- Новая сессия, если субтитров не было 5 минут.
- Файл каждый раз перезаписывается целиком: размер — текст одной встречи.
- Также сохраняется при `onInterrupt` и `onDestroy` службы.

## Формат файла

```
Имя (ЧЧ:ММ:СС)
текст реплики
(строки, если склейка не нашла продолжения)

Другое имя (ЧЧ:ММ:СС)
…
```

`?` вместо имени — имя не найдено ни в тексте, ни в отдельном узле.
